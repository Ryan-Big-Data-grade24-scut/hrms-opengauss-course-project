## 一、整体架构

### 1.1 一句话定义

> **一个让企业"看清人、管好技能、数据驱动决策"的人事操作系统。**

### 1.2 三层架构

```
┌────────────────────────────────────────────────────────┐
│                    前端层 (React + Tailwind)             │
│                                                        │
│  通讯录      Profile       技能管理       数据分析       │
│  /directory  /profile      /skills        /analytics   │
│                                                        │
├────────────────────────────────────────────────────────┤
│                    后端层 (Python API)                   │
│                                                        │
│  directory  │  skill     │  analytics  │  permission   │
│  _service   │  _service  │  _service   │  _service     │
│                                                        │
├────────────────────────────────────────────────────────┤
│                    数据层 (openGauss)                    │
│                                                        │
│  employee   │  skill     │  attendance  │  performance │
│  +profile   │  system    │  _record     │  _review     │
│  +job_hist  │  +CRUD     │  +clock      │  +rating     │
└────────────────────────────────────────────────────────┘
```

## 五、数据库变更

### 现有表追加字段

```sql
-- employee 表追加
ALTER TABLE employee ADD COLUMN attendance_absent_count INTEGER DEFAULT 0;
ALTER TABLE employee ADD COLUMN attendance_late_count INTEGER DEFAULT 0;
ALTER TABLE employee ADD COLUMN avg_performance_score NUMERIC(3,1) DEFAULT 75.0;
```

### 技能系统表（V5 已创建）

```
skill_category → skill → employee_skill
                      → position_required_skill
                      → project_tech_stack ← employee_project
```

### 新增表（V7/V8 迁移）

```sql
CREATE TABLE attendance_record (
    record_id    BIGSERIAL PRIMARY KEY,
    employee_id  BIGINT REFERENCES employee,
    record_date  DATE NOT NULL,
    clock_in     TIMESTAMP,
    clock_out    TIMESTAMP,
    status       VARCHAR(20),  -- ontime/late/absent
    created_by   BIGINT REFERENCES sys_user,
    UNIQUE (employee_id, record_date)
);

CREATE TABLE performance_review (
    review_id      BIGSERIAL PRIMARY KEY,
    employee_id    BIGINT REFERENCES employee,
    reviewer_id    BIGINT REFERENCES sys_user,
    review_period  VARCHAR(20),  -- 2026-Q1
    rating         SMALLINT CHECK(1-5),
    comments       TEXT,
    created_at     TIMESTAMP DEFAULT NOW()
);
```
