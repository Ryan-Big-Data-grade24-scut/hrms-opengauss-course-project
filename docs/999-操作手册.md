## 2. 后端测试指令（curl）

所有 curl 命令基于后端地址 `http://127.0.0.1:18080`。通过前端代理时替换为 `http://127.0.0.1:5177/api`。

### 2.1 登录

```bash
# 管理员登录
curl -s http://127.0.0.1:18080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"Admin@2025#HR"}' | python -m json.tool

# 普通员工登录
curl -s http://127.0.0.1:18080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"employee","password":"Emp@2025"}' | python -m json.tool

# HR经理登录
curl -s http://127.0.0.1:18080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"hr_mgr","password":"HrMgr@2025"}' | python -m json.tool
```

**预期结果**：返回 JSON 包含 `token` 和 `profile`。记录返回的 token 值用于后续请求。

**简化用法（保存token到变量）**：
```bash
TOKEN=$(curl -s http://127.0.0.1:18080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"Admin@2025#HR"}' | python -c "import sys,json;print(json.load(sys.stdin)['data']['token'])")
echo "TOKEN=$TOKEN"
```

### 2.4 提交审批申请

**前置条件**：已登录并获取 TOKEN。根据审批类型准备 payload。

```bash
# ── 技能变更申请 ──
curl -s http://127.0.0.1:18080/api/approval-requests \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "action_type": "SKILL_CHANGE",
    "target_id": null,
    "payload": {
      "employee_id": 1,
      "changes": [
        {"skill_id": 3, "new_level": 4, "reason": "岗位要求提升Python熟练度"}
      ],
      "comment": "申请提升Python等级到4"
    }
  }' | python -m json.tool

# ── 请假申请 ──
curl -s http://127.0.0.1:18080/api/approval-requests \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "action_type": "LEAVE_REQUEST",
    "target_id": null,
    "payload": {
      "leave_type_id": 1,
      "start_date": "2025-06-01",
      "end_date": "2025-06-03",
      "reason": "年假出行"
    }
  }' | python -m json.tool

# ── 考勤补卡申请 ──
curl -s http://127.0.0.1:18080/api/approval-requests \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "action_type": "ATTENDANCE_CORRECTION",
    "target_id": 42,
    "payload": {
      "record_date": "2025-05-20",
      "slot": "morning",
      "clock_in": "09:00",
      "reason": "忘记打卡"
    }
  }' | python -m json.tool

# ── 个人信息修改申请 ──
curl -s http://127.0.0.1:18080/api/approval-requests \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "action_type": "PROFILE_UPDATE",
    "target_id": null,

      "fields": {"phone": "13800138001", "emergency_contact": "张三"},

```

**预期结果**：返回审批申请记录，包含 `request_id` 和当前状态 `pending`。

### 2.5 批准/驳回

```bash
# 查看待审批列表（由具有审批权限的账号操作，如 hr_mgr）
HR_TOKEN=$(curl -s http://127.0.0.1:18080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"hr_mgr","password":"HrMgr@2025"}' | python -c "import sys,json;print(json.load(sys.stdin)['data']['token'])")

curl -s http://127.0.0.1:18080/api/v2/approval-requests/pending \
  -H "Authorization: Bearer $HR_TOKEN" | python -m json.tool

# 批准申请（将 {request_id} 替换为实际的ID，如 1）
curl -s -X PUT http://127.0.0.1:18080/api/v2/approval-requests/1/approve \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $HR_TOKEN" \
  -d '{"comment":"审批通过，符合要求"}' | python -m json.tool

# 驳回申请
curl -s -X PUT http://127.0.0.1:18080/api/v2/approval-requests/1/reject \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $HR_TOKEN" \
  -d '{"comment":"缺少必要信息，请补充"}' | python -m json.tool

# 查看审批详情日志
curl -s http://127.0.0.1:18080/api/v2/approval-requests/1/logs \
  -H "Authorization: Bearer $TOKEN" | python -m json.tool

# 查看我发起的申请
curl -s http://127.0.0.1:18080/api/v2/approval-requests/my \
  -H "Authorization: Bearer $TOKEN" | python -m json.tool

# 查看我处理过的申请
curl -s http://127.0.0.1:18080/api/v2/approval-requests/done \
  -H "Authorization: Bearer $HR_TOKEN" | python -m json.tool
```

**预期结果**：
- `pending` 列表返回待审批申请
- `approve` 返回成功，状态变为 `approved`
- `reject` 返回成功，状态变为 `rejected`
- `logs` 返回审批链操作历史

### 3.2 办事大厅 → 发起申请

#### 3.2.1 技能变更申请（四步选择流程）

| 步骤 | 页面元素 | 操作 | 说明 |
|------|---------|------|------|
| 1 | 导航栏 | 点击"办事大厅" | 进入 ServiceHall 页面 |
| 2 | 页面 | 点击"发起申请"按钮 | 弹出申请类型选择弹窗 |
| 3 | 弹窗 | 选择"技能变更申请" | 进入四步技能选择表单 |
| 4 | Step 1: 部门选择 | 从下拉菜单选择一个部门（如 Engineering） | 调用 `/api/departments` 加载部门列表 |
| 5 | Step 2: 岗位选择 | 根据选定部门，从下拉菜单选择岗位（如 Software Engineer） | 调用 `/api/v2/org-people/positions?department_id={id}` |
| 6 | Step 3: 技能需求展示 | 页面展示该岗位要求的技能卡片列表 | 调用 `/api/skills/required?position_id={id}` |
| 7 | 技能卡片 | 在卡片列表中勾选要添加的技能（如 Python） | 已拥有的技能显示"已有"标记，不能重复选择 |
| 8 | Step 4: 操作面板 | 输入目标熟练度（如 4），填写申请原因 | 熟练度1-5，默认值为岗位目标等级 |
| 9 | 表单底部 | 点击"提交申请"按钮 | 调用 `POST /api/approval-requests` |
| 10 | 页面 | 页面跳转到"我的申请"列表 | 新申请显示状态"待审批" |

**预期结果**：技能选择流程正确限制为部门→岗位→技能需求路径，不能从全局技能列表自由选择。

#### 3.2.2 请假申请

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 在申请类型弹窗选择"请假申请" | 进入请假表单 |
| 2 | 从"请假类型"下拉菜单选择类型（年假/病假/事假） | 调用 `/api/leave-types` 加载 |
| 3 | 选择开始日期和结束日期 | 日期控件 |
| 4 | 页面自动计算天数和可用假期余额 | 显示"共X天，剩余假期Y天" |
| 5 | 填写请假原因 | 必填文本域 |
| 6 | 点击"提交申请" | 提交审批 |

**预期结果**：
- 天数自动计算（endDate - startDate + 1）
- 显示当前可用假期余额
- 提交后状态为"待审批"

#### 3.2.3 考勤补卡申请

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 在申请类型弹窗选择"考勤补卡申请" | 进入补卡表单 |
| 2 | 选择补卡日期 | 日期控件，不可选未来日期 |
| 3 | 选择时段：上午/下午/全天 | 单选按钮 |
| 4 | 上午时段填写打卡时间（clock_in） | 时间选择器 |
| 5 | 下午时段填写签退时间（clock_out） | 时间选择器 |
| 6 | 填写补卡原因 | 必填文本域 |
| 7 | 点击"提交申请" | 提交审批 |

**预期结果**：
- 日期不可选择未来日期
- 上午只填 clock_in，下午只填 clock_out，全天填两者
- 提交后状态为"待审批"

#### 3.2.4 个人信息修改申请

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 在申请类型弹窗选择"个人信息修改" | 进入信息修改表单 |
| 2 | 填写要修改的字段（电话/紧急联系人/邮箱等） | 表单字段 |
| 3 | 填写修改原因 | 必填文本域 |
| 4 | 点击"提交申请" | 提交审批 |

**预期结果**：提交后状态为"待审批"，审批通过后数据更新。

#### 3.2.5 审批列表操作

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 在办事大厅页面点击"待我审批"标签 | 查看待审批列表（仅审批人有数据） |
