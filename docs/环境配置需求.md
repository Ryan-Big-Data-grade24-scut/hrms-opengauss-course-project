## 一、容器环境（Docker）

### 1.1 openGauss

| 参数 | 值 |
|------|-----|
| 镜像 | `opengauss/opengauss:latest` |
| 镜像 ID | `a10ed4705e78` |
| 构建时间 | 2025年初（约 14 个月前） |
| 容器名 | `opengauss-hrms` |
| 端口映射 | `5432:5432` |
| 数据卷 | `opengauss-hrms-data:/var/lib/opengauss` |
| 密码 | `OpenGauss123!` |
| 默认用户 | `omm` |
| 应用用户 | `hrms_app`（密码 `HRMS_App_2026!`） |

### 1.2 容器启动命令

```bash
docker run --name opengauss-hrms --privileged=true -d \
    -e GS_PASSWORD=OpenGauss123! \
    -e GS_NODENAME=gaussdb \
    -p 5432:5432 \
    -v opengauss-hrms-data:/var/lib/opengauss \
    opengauss/opengauss:latest
```

### 1.3 数据库初始化

```sql
-- 创建应用用户（解决 omm 禁止远程 TCP 连接的问题）
CREATE USER hrms_app WITH PASSWORD 'HRMS_App_2026!' SYSADMIN;
GRANT ALL PRIVILEGES TO hrms_app;

-- 创建业务库
CREATE DATABASE hrms;
```

### 1.4 pg_hba.conf 规则

```
local   all             all                                     trust
host    all             all             127.0.0.1/32            trust
host    all             all             ::1/128                 trust
host    all             all             0.0.0.0/0               md5
```

## 二、Python 环境（后端）

### 2.1 版本要求

| 项目 | 版本 |
|------|------|
| Python | 3.12+ |
| pip | 最新版 |

### 2.2 Python 依赖

```txt
psycopg2-binary>=2.9       # openGauss/PostgreSQL 直连（已安装）
```

> 注意：`psycopg2-binary` 替换了原来的 `docker exec + gsql` 模式。
> 旧模式每次查询创建 Docker 进程（~0.4s 开销），新模式直连（~0.01s）。

### 2.3 后端配置

```python
# backend/src/config.py
APP_HOST = "127.0.0.1"
APP_PORT = 18080

DOCKER_CONTAINER = "opengauss-hrms"   # 仅 gsql 模式使用
DB_NAME = "hrms"
DB_USER = "hrms_app"                  # 非 omm（omm 禁止远程连接）
DB_PASSWORD = "HRMS_App_2026!"
DB_HOST = "127.0.0.1"
DB_PORT = "5432"
```

### 2.4 启动方式

```bash
cd backend
python app.py
# 后端监听 http://localhost:18080
```

## 六、常见问题

### 6.1 端口占用（Zombie 进程）

```bash
# 查找并杀掉所有占用 18080 和 5173 的进程
netstat -ano | grep 18080 | grep LISTEN | awk '{print $5}' | xargs -I{} taskkill /F /PID {}
netstat -ano | grep 5173 | grep LISTEN | awk '{print $5}' | xargs -I{} taskkill /F /PID {}
```

### 6.2 V10 迁移丢失（重启后）

```bash
docker cp sql/migrations/V10__approval_workflow.sql opengauss-hrms:/tmp/V10.sql
docker exec -e LD_LIBRARY_PATH=/usr/local/opengauss/lib opengauss-hrms \
    gsql -h 127.0.0.1 -p 5432 -d hrms -U omm -W OpenGauss123! -f /tmp/V10.sql
```

### 6.3 openGauss 禁止 omm 远程连接

openGauss 安全限制：初始用户 `omm` 不允许 TCP/IP 远程连接。
解决方式：新建 `hrms_app` 用户（SYSADMIN）。
已在 `config.py` 中默认使用 `hrms_app`。

### 6.4 镜像版本选择

当前使用 `opengauss/opengauss:latest`。如需特定版本：

```bash
# 查看可用标签
docker search opengauss --limit 10
# 或访问 https://hub.docker.com/r/opengauss/opengauss/tags

# 使用指定版本
docker run --name opengauss-hrms ... opengauss/opengauss:7.0.0
```

### 6.5 psycopg2 兼容性

openGauss 7.0.0 兼容 PostgreSQL 线层协议，`psycopg2` 可直连。
已知限制：
- `cursor.nextset()` 不支持（openGauss 不支持多语句结果集）
- JSON 操作符 `->>` 需要列类型为 `json` 而非 `text`
